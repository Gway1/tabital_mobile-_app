# Tabital brand files

Made by `tool/make_brand_icons.py` from the real Tabital mark.

- **Source:** `tabital_front/brand/source/mark.png` (1182×889, transparent), added to the main project in commit `6082925` (2026-09-26, "Real Tabital logo"). It is the same artwork as tabitalpay.com's site icon (`/wp-content/uploads/2026/09/tabital-pay-site-icon-512.png`) and mark (`/wp-content/uploads/2026/09/tabital-pay-mark-256.png`). Nothing was downloaded: the files came from the main project.
- `mark.png`: the mark on a transparent background, 1024 px wide. The app shows this one.
- `mark-256.png`: the mark on a transparent background, 256 px.
- `icon-512.png`: the mark on navy (#02163F), as the launcher icon.

There is no wordmark file: "Tabital Pay" is set in Poppins. When the founder supplies an SVG or a 1024 px+ original, put it in `tabital_front/brand/source/` and rerun the script.
